## 1. Objective

HaberNexus platformuna kullanıcı profilleri, takip sistemi ve bildirim sistemi ekleyerek topluluk özelliklerini hayata geçirmek.

## 2. Research & Findings

- **Next.js App Router:** Dinamik kullanıcı profil sayfaları için `/profil/[username]` route yapısı kullanılacak
- **Prisma:** Takip ilişkileri için self-referencing many-to-many relation kullanılacak
- **Real-time Notifications:** Server-sent events (SSE) veya polling ile bildirimler gösterilecek
- **Auth.js v5:** Mevcut oturum sistemi kullanılarak kullanıcı kimlik doğrulaması yapılacak

## 3. Step-by-Step Implementation

### Faz 1: Veritabanı Şeması (Prisma)

1. **UserProfile modeli genişletme:**
   - bio (biyografi)
   - website
   - location
   - username (benzersiz, URL-friendly)
   - coverImage (kapak fotoğrafı)

2. **Follow modeli ekleme:**
   - followerId (takip eden)
   - followingId (takip edilen)
   - createdAt

3. **Notification modeli ekleme:**
   - userId (bildirim sahibi)
   - type (follow, comment, like, article)
   - message
   - link
   - isRead
   - createdAt
   - actorId (bildirimi tetikleyen kullanıcı)

### Faz 2: API Endpoints

1. **Profil API'leri:**
   - GET /api/users/[username] - Profil bilgilerini getir
   - PATCH /api/users/[username] - Profil güncelle
   - GET /api/users/[username]/articles - Kullanıcının makaleleri
   - GET /api/users/[username]/bookmarks - Kullanıcının yer işaretleri

2. **Takip API'leri:**
   - POST /api/follow - Takip et
   - DELETE /api/follow - Takibi bırak
   - GET /api/users/[username]/followers - Takipçiler
   - GET /api/users/[username]/following - Takip edilenler

3. **Bildirim API'leri:**
   - GET /api/notifications - Bildirimleri listele
   - PATCH /api/notifications/[id] - Okundu işaretle
   - PATCH /api/notifications/read-all - Tümünü okundu işaretle
   - GET /api/notifications/count - Okunmamış sayısı

### Faz 3: UI Bileşenleri

1. **Profil Sayfası:**
   - /profil/[username]/page.tsx
   - ProfileHeader (avatar, isim, bio, takipçi sayıları)
   - ProfileTabs (Makaleler, Yer İşaretleri, Beğenilenler)
   - FollowButton

2. **Profil Düzenleme:**
   - /profil/duzenle/page.tsx
   - ProfileEditForm

3. **Bildirim Bileşenleri:**
   - NotificationBell (Header'da)
   - NotificationDropdown
   - NotificationItem
   - /bildirimler/page.tsx (tüm bildirimler)

4. **Takip Bileşenleri:**
   - FollowButton
   - FollowersList
   - FollowingList

### Faz 4: Header Entegrasyonu

1. Header'a profil linki ekleme
2. Bildirim ikonu ekleme
3. Dropdown menüye profil linki ekleme
