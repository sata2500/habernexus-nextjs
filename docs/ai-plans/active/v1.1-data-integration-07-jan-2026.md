## 1. Objective

Demo verilerden gerçek veritabanı entegrasyonuna geçiş yaparak, haber detay sayfası, kategori sayfası, bookmark API, oylama API, görüntülenme sayacı API ve newsletter API'lerini işlevsel hale getirmek.

## 2. Research & Findings

- **Next.js App Router:** Server Components ile veritabanı sorguları doğrudan yapılabilir. Client Components için API route'lar gerekli.
- **Prisma:** Veritabanı sorguları için `prisma.article.findUnique()`, `prisma.article.findMany()` gibi metodlar kullanılacak.
- **Auth.js:** Oturum bilgisi `auth()` fonksiyonu ile alınabilir. Korumalı API'ler için session kontrolü gerekli.
