## 1. Objective

Demo verilerden gerçek veritabanı entegrasyonuna geçiş yaparak, haber detay sayfası, kategori sayfası, bookmark API, oylama API, görüntülenme sayacı API ve newsletter API'lerini işlevsel hale getirmek.

## 2. Research & Findings

- **Next.js App Router:** Server Components ile veritabanı sorguları doğrudan yapılabilir. Client Components için API route'lar gerekli.
- **Prisma:** Veritabanı sorguları için `prisma.article.findUnique()`, `prisma.article.findMany()` gibi metodlar kullanılacak.
- **Auth.js:** Oturum bilgisi `auth()` fonksiyonu ile alınabilir. Korumalı API'ler için session kontrolü gerekli.

## 3. Step-by-Step Implementation

### Micro-Step 1: Haber Detay Sayfası Veri Entegrasyonu
- **Dosyalar:** `app/haber/[slug]/page.tsx`
- **İşlem:** Demo veri yerine Prisma ile veritabanından çekme
- **Doğrulama:** `npx tsc --noEmit && npm run build`

### Micro-Step 2: Kategori Sayfası Veri Entegrasyonu
- **Dosyalar:** `app/kategori/[slug]/page.tsx`
- **İşlem:** Demo veri yerine Prisma ile veritabanından çekme, sayfalama desteği
- **Doğrulama:** `npx tsc --noEmit && npm run build`

### Micro-Step 3: Ana Sayfa Veri Entegrasyonu
- **Dosyalar:** `components/home/LatestNews.tsx`, `components/home/PopularNews.tsx`
- **İşlem:** Demo veri yerine Prisma ile veritabanından çekme
- **Doğrulama:** `npx tsc --noEmit && npm run build`

### Micro-Step 4: Görüntülenme Sayacı API
- **Dosyalar:** `app/api/articles/[id]/view/route.ts`
- **İşlem:** viewCount artırma endpoint'i oluşturma
- **Doğrulama:** `npx tsc --noEmit && npm run build`

### Micro-Step 5: Bookmark API
- **Dosyalar:** `app/api/bookmarks/route.ts`, `app/api/bookmarks/[articleId]/route.ts`
- **İşlem:** Bookmark ekleme/kaldırma/listeleme endpoint'leri
- **Doğrulama:** `npx tsc --noEmit && npm run build`

### Micro-Step 6: Makale Oylama API
- **Dosyalar:** `app/api/articles/[id]/vote/route.ts`
- **İşlem:** Oy verme/geri çekme endpoint'i
- **Doğrulama:** `npx tsc --noEmit && npm run build`

### Micro-Step 7: Newsletter API
- **Dosyalar:** `app/api/newsletter/route.ts`
- **İşlem:** E-posta abonelik endpoint'i
- **Doğrulama:** `npx tsc --noEmit && npm run build`

### Micro-Step 8: UI Entegrasyonu
- **Dosyalar:** `app/haber/[slug]/page.tsx`, `components/home/NewsletterSection.tsx`
- **İşlem:** API'leri UI bileşenlerine bağlama
- **Doğrulama:** `npx tsc --noEmit && npm run build && npm run dev`
