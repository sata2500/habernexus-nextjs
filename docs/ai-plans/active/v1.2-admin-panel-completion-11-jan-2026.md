# Development Plan: v1.2 Admin Panel Tamamlama

- **Issue:** ROADMAP v1.2
- **Agent:** Manus AI
- **Status:** In Progress

## 1. Objective

ROADMAP.md'de belirtilen v1.2 sürümündeki Admin Panel özelliklerini tamamlamak: Kullanıcı Yönetimi, Makale Yönetimi, Ayarlar ve Analitik sayfalarını işlevsel hale getirmek.

## 2. Research & Findings

- **Next.js 14+ App Router:** Server Components ve Server Actions kullanımı önerilir
- **Prisma ORM:** Veritabanı işlemleri için type-safe sorgular
- **Auth.js v5:** Oturum kontrolü ve rol tabanlı erişim
- **Tailwind CSS:** Mevcut UI stiline uygun tasarım

## 3. Step-by-Step Implementation

### Micro-Step 1: Admin Kullanıcı Yönetimi Sayfası
- **Dosyalar:** `app/admin/kullanicilar/page.tsx`
- **Özellikler:** Kullanıcı listesi, rol değiştirme, silme
- **Doğrulama:** tsc + lint + build

### Micro-Step 2: Admin Kullanıcı API'leri
- **Dosyalar:** `app/api/admin/users/route.ts`, `app/api/admin/users/[id]/route.ts`
- **Özellikler:** GET (liste), PATCH (rol güncelle), DELETE (sil)
- **Doğrulama:** tsc + lint + build

### Micro-Step 3: Admin Makale Yönetimi Sayfası
- **Dosyalar:** `app/admin/makaleler/page.tsx`
- **Özellikler:** Makale listesi, düzenleme, silme, yayın durumu
- **Doğrulama:** tsc + lint + build

### Micro-Step 4: Admin Makale API'leri
- **Dosyalar:** `app/api/admin/articles/route.ts`, `app/api/admin/articles/[id]/route.ts`
- **Özellikler:** GET (liste), PATCH (güncelle), DELETE (sil)
- **Doğrulama:** tsc + lint + build

### Micro-Step 5: Admin Ayarlar Sayfası
- **Dosyalar:** `app/admin/ayarlar/page.tsx`
- **Özellikler:** Sistem ayarları görüntüleme ve düzenleme
- **Doğrulama:** tsc + lint + build

### Micro-Step 6: Admin Ayarlar API'leri
- **Dosyalar:** `app/api/admin/settings/route.ts`
- **Özellikler:** GET (ayarları getir), PUT (ayarları güncelle)
- **Doğrulama:** tsc + lint + build

### Micro-Step 7: Admin Analitik Sayfası
- **Dosyalar:** `app/admin/analitik/page.tsx`
- **Özellikler:** Gerçek metrikler, grafikler
- **Doğrulama:** tsc + lint + build
