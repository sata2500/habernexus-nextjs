# HaberNexus v3.0.0 - Topluluk Özellikleri

**Yayın Tarihi:** 17 Ocak 2026  
**Geliştirici:** Manus AI

---

## Özet

Bu sürüm, HaberNexus platformuna kapsamlı topluluk özellikleri eklemektedir. Kullanıcılar artık profil sayfalarına sahip olabilir, birbirlerini takip edebilir ve bildirimler alabilir.

---

## Yeni Özellikler

### Kullanıcı Profilleri

Kullanıcılar artık kendi profil sayfalarına sahip. Profil sayfaları şu bilgileri içerir:

- **Profil Bilgileri:** İsim, kullanıcı adı, biyografi, konum, web sitesi
- **Kapak Fotoğrafı:** Özelleştirilebilir kapak görseli
- **İstatistikler:** Takipçi sayısı, takip edilen sayısı, makale sayısı
- **Makaleler:** Kullanıcının yazdığı makaleler
- **Yer İşaretleri:** Kullanıcının kaydettiği makaleler (sadece kendi profilinde görünür)

**Sayfalar:**
- `/profil/[username]` - Profil sayfası
- `/profil/duzenle` - Profil düzenleme sayfası

### Takip Sistemi

Kullanıcılar birbirlerini takip edebilir:

- **Takip Et/Takibi Bırak:** Tek tıkla takip işlemi
- **Takipçi Listesi:** `/profil/[username]/takipciler`
- **Takip Edilenler Listesi:** `/profil/[username]/takip-edilenler`
- **Takip Bildirimi:** Takip edildiğinde bildirim gönderilir

### Bildirim Sistemi

Kapsamlı bildirim sistemi:

- **Bildirim Türleri:**
  - Takip bildirimleri
  - Yorum bildirimleri
  - Beğeni bildirimleri
  - Sistem bildirimleri

- **Bildirim İkonu:** Header'da okunmamış bildirim sayısı gösterilir
- **Dropdown Menü:** Son 5 bildirim hızlıca görüntülenebilir
- **Bildirimler Sayfası:** `/bildirimler` - Tüm bildirimler
- **Okundu İşaretleme:** Tek tek veya toplu okundu işaretleme
- **Bildirim Silme:** İstenmeyen bildirimler silinebilir

## Teknik Değişiklikler

### Veritabanı Şeması

**User Modeli Güncellemeleri:**
```prisma
model User {
  // Yeni profil alanları
  username      String?   @unique
  bio           String?
  website       String?
  location      String?
  coverImage    String?
  
  // Yeni ilişkiler
  followers     Follow[]  @relation("Following")
  following     Follow[]  @relation("Followers")
  notifications Notification[]
}
```

**Yeni Modeller:**
```prisma
model Follow {
  id          String   @id @default(cuid())
  followerId  String
  followingId String
  createdAt   DateTime @default(now())
  
  @@unique([followerId, followingId])
}

model Notification {
  id        String           @id @default(cuid())
  userId    String
  actorId   String?
  type      NotificationType
  message   String
  link      String?
  isRead    Boolean          @default(false)
  createdAt DateTime         @default(now())
}
```

### API Endpoints

| Endpoint | Method | Açıklama |
|----------|--------|----------|
| `/api/users/[username]` | GET | Kullanıcı profili getir |
| `/api/users/[username]` | PATCH | Profil güncelle |
| `/api/users/[username]/articles` | GET | Kullanıcının makaleleri |
| `/api/users/[username]/followers` | GET | Takipçi listesi |
| `/api/users/[username]/following` | GET | Takip edilenler listesi |
| `/api/follow` | GET | Takip durumu kontrol |
| `/api/follow` | POST | Takip et |
| `/api/follow` | DELETE | Takibi bırak |
| `/api/notifications` | GET | Bildirimleri listele |
| `/api/notifications` | PATCH | Tümünü okundu işaretle |
| `/api/notifications/[id]` | PATCH | Tek bildirimi okundu işaretle |
| `/api/notifications/[id]` | DELETE | Bildirim sil |
| `/api/notifications/count` | GET | Okunmamış bildirim sayısı |

### Bileşenler

**Profil Bileşenleri:**
- `ProfileHeader` - Profil başlık bölümü
- `ProfileTabs` - Makaleler ve yer işaretleri sekmeleri
- `FollowButton` - Takip et/bırak butonu
- `UserCard` - Kullanıcı kartı (takipçi listelerinde)

**Bildirim Bileşenleri:**
- `NotificationBell` - Header'daki bildirim ikonu ve dropdown
